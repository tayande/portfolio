PaddyCredit

A full-stack micro-lending platform where borrowers apply for small loans, repay with uploaded receipts and unlock bigger loans as they build a repayment history.

Python Django PostgreSQL SendGrid Cloudinary GitHub Actions

Overview

About the project

PaddyCredit is a lending web application built with Django. Borrowers create an account, apply for a loan between ₦5,000 and ₦100,000, and every application is reviewed by an admin before the money is paid straight to the borrower's bank account.

Each loan moves through a full lifecycle, from pending and approved to disbursed, partially repaid, repaid or defaulted. Interest, penalties and outstanding balances are calculated with exact decimal arithmetic, and borrowers who repay in full can borrow more next time.

The project gave me practical experience designing a multi-app Django codebase, modelling real financial workflows, securing user accounts, writing over 150 automated tests and running a production application on Render with a managed PostgreSQL database.

Features

What it does

  • Borrower accounts with email verification, password reset and email change using one-time codes
  • Loan applications with a flat 20% interest rate over a 30-day repayment period
  • Borrowing limit that grows by 50% after each fully repaid loan, up to ₦100,000
  • Repayments submitted as receipt uploads and confirmed by an admin, with support for partial payments
  • Admin dashboard for reviewing applications, disbursing loans, confirming repayments and managing users, with a log of admin actions
  • Automated daily job that emails reminders before a loan is due and applies penalties to overdue loans
  • In-app notifications, email updates and a support thread between borrowers and admins
  • Protection against brute-force attacks, including login lockouts and hashed, rate-limited one-time codes
