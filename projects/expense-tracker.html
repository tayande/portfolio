Personal Expense Tracker

A web application for recording and managing personal expenses using Python, Flask and JSON.

Python Flask HTML CSS JSON

Overview

About the project

The Personal Expense Tracker is a web application built to help users record and manage their expenses through a simple browser-based interface.

The project gave me practical experience building a web application with Python and Flask, connecting a frontend interface to backend application logic and working with JSON-based data.

Features

What it does

  • Records personal expenses
  • Provides a web-based interface for interacting with expense data
  • Processes expense information through a Flask backend
  • Works with JSON for data storage and handling
  • Uses HTML and CSS for the user interface
