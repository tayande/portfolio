Overview

About the project

Groupie Tracker is a web application built with Go that works with data provided by an external API.

The application presents information about artists and bands, including their members, concert dates and relationships between different pieces of data.

This project gave me practical experience working with APIs, JSON data, HTTP requests, server-side rendering and web application development with Go.

Features

What it does

  • Retrieves data from an external API
  • Displays artists and bands
  • Shows artist and band members
  • Displays concert dates
  • Presents relationships between different API data
  • Uses a Go HTTP server to serve the web application
