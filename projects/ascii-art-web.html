ASCII Art Web

A Go web application that provides a browser-based interface for generating ASCII art.

Go net/http HTML CSS

Overview

About the project

ASCII Art Web is a web-based version of an ASCII art generator. It allows users to interact with the application through a browser rather than using a command-line interface.

The project provided practical experience with Go web development, HTTP servers, routing, HTML templates, form handling and serving web pages.

Features

What it does

  • Provides a browser-based interface for ASCII art generation
  • Accepts user input through a web form
  • Processes the input using Go
  • Uses an HTTP server to handle browser requests
  • Displays generated ASCII art in the browser
